# gorsel-donusturucu
sitede dosya seç butonuna basıp bi görsel seçiyorsunuz. site arka planda görseli 320x240 yatay boyutuna getirir. sonra siyah kutucuk içinde yeni oluşturulmuş görselin önizlemesi görünür. Daha sonra alttan "kodu kopyala" butonuna basarak hex kodu elde edersiniz. oluşturulan hex kodu dediğim gibi 320x240 pikseldir. ILI9341 üzerinde çalıştırırsınız.
